# Forcing

A [Lean 4](https://lean-lang.org/) project built against
[mathlib](https://github.com/leanprover-community/mathlib4).

- Toolchain: `leanprover/lean4:v4.32.2`
- Mathlib: pinned to the `v4.32.2` tag

## Building

```sh
lake exe cache get
lake build
```
